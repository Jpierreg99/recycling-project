Machine Learning Model

This phase focuses on the implementation of Machine Learning techniques to analyze demographic behavior and sustainability patterns related to urban recycling systems in Bogotá.

The project uses the K-Means clustering algorithm from Scikit-learn to identify hidden population groups based on normalized demographic variables.

The Machine Learning workflow includes:

  • Data preprocessing
  • Feature normalization
  • Model training using fit()
  • Predictions using predict()
  • Cluster visualization
  • Processed dataset generation

Model Training Process

The Machine Learning model was developed using the Scikit-learn library in Python.

The dataset was normalized using MinMaxScaler to ensure consistent variable scaling before training.

The K-Means algorithm was configured with:

  • 4 clusters
  • Random state = 42
  • Normalized population feature

The training process was executed using: 

kmeans.fit(X)
population['CLUSTER'] = kmeans.predict(X)

Machine Learning Results

The model successfully classified demographic records into multiple behavioral groups.

These clusters help identify population density patterns, sustainability indicators, and recycling behavior trends across Bogotá.

The processed dataset was exported automatically after training and stored inside the processed data folder.

Data Normalization

Before training the Machine Learning model, the population variable was normalized using Min-Max Scaling techniques.

Normalization ensures that values remain within a consistent numerical range, improving clustering performance and reducing the impact of scale differences between records.

The preprocessing stage is considered a critical component of the CRISP-ML methodology and contributes directly to model stability.

Correlation Analysis

Correlation analysis was performed to evaluate relationships between numerical variables contained within the demographic dataset.

The heatmap visualization helps identify positive and negative correlations between variables, supporting feature selection and Machine Learning preprocessing decisions.

Statistical Summary

Statistical analysis was performed to better understand the distribution of numerical variables within the dataset.

Important metrics such as mean, standard deviation, minimum values, maximum values, and quartiles were analyzed during the Data Understanding phase.

This analysis helped identify data consistency, detect possible anomalies, and support preprocessing decisions before Machine Learning implementation.

The clustering analysis successfully identified multiple demographic behavior groups within the dataset.
