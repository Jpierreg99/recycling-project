Population Normalization

from sklearn.preprocessing import MinMaxScaler

scaler = MinMaxScaler()

population['POPULATION_NORMALIZED'] = scaler.fit_transform(
    population[['POBLACION']]
)

Min-Max normalization scaled population values into a range between 0 and 1, improving clustering performance and reducing numerical bias during Machine Learning training.

Machine Learning Preparation

X = population[['POPULATION_NORMALIZED']]

kmeans.fit(X)

population['CLUSTER'] = kmeans.predict(X)

The normalized dataset was prepared for K-Means clustering analysis using Scikit-learn. The clustering algorithm grouped demographic records according to behavioral population patterns.
